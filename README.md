# LOAN-APPROVAL-ANALYSIS
The Loan Sanction Dataset contains customer and financial information used to predict whether a loan application will be approved or not. It includes details such as gender, marital status, education, employment status, applicant income, co-applicant income, loan amount, loan term, credit history, and property area. The dataset consists of both categorical and numerical variables, making it suitable for Exploratory Data Analysis (EDA), data visualization, and machine learning classification models. This dataset helps banks and financial institutions analyze customer eligibility, identify financial risk, improve loan approval decisions, and develop predictive models to automate and enhance the loan sanction process efficiently.
